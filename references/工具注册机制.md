# 工具注册机制

> 12 种标准工具 + agent_call 多 Agent 委托工具

---

## 一、统一接口规范

所有工具必须实现 `AgentTool` 接口：

```typescript
import { z } from "zod";

interface AgentTool {
  /** 工具唯一标识，LLM 用这个名字决定调哪个 */
  name: string;

  /** 工具能力描述（给 LLM 看的 system prompt 用）*/
  description: string;

  /** 参数校验 Schema，拦截 LLM 瞎传的参数 */
  parameters: z.ZodType;

  /** 执行逻辑 */
  execute: (
    params: unknown,
    context: ToolContext
  ) => Promise<ToolResult>;
}

interface ToolContext {
  agentId: string;                    // 谁在调这个工具
  store: GlobalState;                 // 全局状态（可读写虚拟文件系统等）
  scheduler?: AgentScheduler;         // 仅 agent_call 工具用
}

interface ToolResult {
  success: boolean;
  output: string;        // LLM 看到的主要返回
  raw?: unknown;         // 结构化数据（可选）
  artifacts?: Artifact[]; // 产生的文件/图表
}
```

## 二、12 种工具清单

### 2.1 文件系统（4 种，操作共享虚拟文件系统）

| name | description | 核心逻辑 |
|------|-------------|---------|
| `file_read` | 读取文件内容 | `store.virtualFileSystem.files[path]` |
| `file_write` | 写文件（创建或覆盖） | `store.virtualFileSystem.files[path] = content` |
| `file_edit` | 编辑文件（old→new 替换） | 读取 → replace → 写回 |
| `file_search` | 搜索文件（glob 模式） | 在 VFS 中按模式匹配路径 |

### 2.2 代码执行（1 种）

| name | description | 核心逻辑 |
|------|-------------|---------|
| `python_exec` | 执行 Python 代码 | Pyodide WASM 动态加载，`pyodide.runPython(code)` |

加载时机：首次执行 Python 工具时才 import Pyodide，避免阻塞首屏。

```typescript
const pyodide = await import("pyodide").then(m => m.loadPyodide());
const result = await pyodide.runPythonAsync(code);
```

### 2.3 Shell（1 种，前端模拟）

| name | description | 核心逻辑 |
|------|-------------|---------|
| `shell` | 模拟 Shell 命令 | 前端解析管道 `|`、通配符 `*`、支持 grep/find/wc/ls/echo |

模拟范围：管道、通配符、`find -exec`、`wc -l`、`grep pattern`、`ls -la`、`echo`、`cat`、`sort`、`uniq`。输出基于虚拟文件系统。

### 2.4 网络（3 种）

| name | description | 核心逻辑 |
|------|-------------|---------|
| `web_search` | 网络搜索 | mock 返回（演示）或调用搜索 API |
| `web_fetch` | 抓取网页内容 | `fetch(url)` + HTML→Markdown |
| `http_request` | 通用 HTTP 调用 | `fetch()` 支持 method/headers/body |

### 2.5 用户交互（1 种）

| name | description | 核心逻辑 |
|------|-------------|---------|
| `user_input` | 请求用户输入 | UI 弹窗，Agent 状态变为 awaiting_input，等待用户回复 |

### 2.6 多 Agent 核心工具（1 种）

| name | description | 核心逻辑 |
|------|-------------|---------|
| `agent_call` | 委托给另一个 Agent | 调 `context.scheduler.executeAgent(agentId, task)`，同步等待子 Agent 完成 |

这是多 Agent 协作的关键。每个 Agent 的 system prompt 里自动注入"可用的子 Agent 列表"，LLM 就知道该委托给谁了。

## 三、注册中心

```typescript
class ToolRegistry {
  private tools: Map<string, AgentTool> = new Map();

  register(tool: AgentTool): void {
    this.tools.set(tool.name, tool);
  }

  get(name: string): AgentTool | undefined {
    return this.tools.get(name);
  }

  // 给 LLM 的 system prompt 用：列出所有可用工具
  getToolDescriptions(): Array<{ name: string; description: string; parameters: unknown }> {
    return Array.from(this.tools.values()).map(t => ({
      name: t.name,
      description: t.description,
      parameters: t.parameters,
    }));
  }
}

// 使用
const registry = new ToolRegistry();
for (const tool of defaultTools) {
  registry.register(tool);
}
```

## 四、添加自定义工具

步骤：

1. `src/tools/` 下新建文件，实现 `AgentTool` 接口
2. 在 `src/tools/index.ts` 的 `defaultTools` 数组中加入 `new MyCustomTool()`
3. 完事——新工具自动出现在 LLM 的 system prompt 中

示例：添加一个"查数据库"工具

```typescript
// src/tools/DbQueryTool.ts
import { z } from "zod";
import type { AgentTool, ToolContext, ToolResult } from "../types";

export class DbQueryTool implements AgentTool {
  name = "db_query";
  description = "查询数据库。参数: { table: string, sql: string }。返回查询结果。";
  parameters = z.object({
    table: z.string(),
    sql: z.string(),
  });

  async execute(
    params: { table: string; sql: string },
    context: ToolContext
  ): Promise<ToolResult> {
    // 你的查询逻辑（可以调后端 API、mock 数据等）
    const rows = await fetch(`/api/query`, {
      method: "POST",
      body: JSON.stringify(params),
    }).then(r => r.json());

    return {
      success: true,
      output: `查询到 ${rows.length} 条记录`,
      raw: rows,
    };
  }
}
```

## 五、关闭/替换工具

### 关闭不需要的工具

编辑 `src/tools/index.ts`，从 `defaultTools` 数组中移除：

```typescript
// 纯前端演示不需要 shell？注释掉
const defaultTools: AgentTool[] = [
  new FileReadTool(),
  new FileWriteTool(),
  // new ShellTool(),  // 注释掉就不注册了
  new PythonExecTool(),
  // ...
];
```

### 替换实现

如果想把 Python 执行从 Pyodide 改成后端服务：

```typescript
export class PythonExecTool implements AgentTool {
  async execute(params, context) {
    const { code } = params as { code: string };
    // 调后端 API 而不是 Pyodide
    const result = await fetch("/api/python", {
      method: "POST",
      body: JSON.stringify({ code }),
    }).then(r => r.json());
    
    return {
      success: result.success,
      output: result.output,
      error: result.error,
    };
  }
}
```

接口不变，只改 execute 实现，其他代码零影响。
