## 一、场景文件结构

```typescript
// 场景 = DAG 拓扑 + Agent 定义 + 用户初始指令
export interface SceneConfig {
  /** DAG 拓扑定义 */
  dag: {
    /** 所有 Agent ID 列表 */
    agents: string[];
    /** Agent 间的边关系 */
    edges: Array<{
      from: string;
      to: string;
      type: "delegate" | "depends_on" | "parallel";
      description?: string;
    }>;
    /** 入口 Agent（谁先启动） */
    entryAgentId: string;
  };

  /** Agent 详细配置 */
  agents: Array<{
    id: string;
    name: string;
    systemPrompt: string;
  }>;

  /** 用户初始指令 */
  userPrompt: string;

  /** 场景元信息 */
  meta?: {
    title?: string;
    description?: string;
    tags?: string[];
  };
}
```

## 三、自定义场景快速写法

### Step 1：创建场景文件

```
src/presets/myScene.ts
```

### Step 2：填 DAG 和 Agent

参考上面的模板，核心就两块：

**简单多 Agent 委托链：**
```typescript
dag: {
  agents: ["a", "b", "c"],
  edges: [
    { from: "a", to: "b", type: "delegate" },
    { from: "b", to: "c", type: "delegate" },
  ],
  entryAgentId: "a",
}
```

**并行 + 汇总：**
```typescript
dag: {
  agents: ["planner", "searcher1", "searcher2", "writer"],
  edges: [
    { from: "planner", to: "searcher1", type: "parallel" },
    { from: "planner", to: "searcher2", type: "parallel" },
    { from: "searcher1", to: "writer", type: "depends_on" },
    { from: "searcher2", to: "writer", type: "depends_on" },
  ],
  entryAgentId: "planner",
}
```

### Step 3：在 App.tsx 里引入

```typescript
import myScene from "./presets/myScene";

// 改为使用你的场景
const scene = myScene;
```

## 四、虚拟文件系统预置文件

场景启动时，可以在虚拟文件系统里预置一些文件（模拟用户上传的输入数据）：

```typescript
// 在 SceneConfig 里加一个可选字段
interface SceneConfig {
  // ... 原有字段
  initialFiles?: Array<{
    path: string;
    content: string;
    type?: "text" | "csv" | "markdown" | "json";
  }>;
}

// 例子：旅行攻略场景预置用户数据
const travelPlanner: SceneConfig = {
  // ...
  initialFiles: [
    {
      path: "/workspace/destinations.md",
      type: "markdown",
      content: `# 候选目的地\n- 京都 5天\n- 大阪 3天\n- 东京 4天\n`,
    },
    {
      path: "/workspace/budget.csv",
      type: "csv",
      content: `项目,预算(元)\n机票往返,3000\n住宿,4000\n餐饮,2500\n交通,1500\n门票,1000\n合计,12000\n`,
    },
  ],
};
```

Agent 启动时这些文件就存在于虚拟文件系统中，可以直接用 `file_read` 读取。
